Я делаю сервис для изучения английского языка при помощи изучения новых слов через контекст

Глобально процесс изучения состоит в следующем:
- Пользователь получает определение случайного слова на изучаемом языке
- Пользователь предполагает загаданное слово и отправляет его в сервис
- Сервис проверяет, верно ли пользователь предположил слово
- Если верно, то сервис отправляет пользователю сообщение с благодарностью за ответ и загадывает новое слово
- Если не верно, то сервис отправляет пользователю сообщение с грустным смайликом. Пользователь пробует снова

Есть режим настроек, который позволяет:
- Выбрать базовый язык
- Выбрать изучаемый язык
- Выбрать уровень сложности

Есть режим добавления слов в словарь
- Пользователь отправляет список слов
- Сервис проверяет, какие слова уже есть в словаре
- Новые слова добавляются в словарь
- Сервис показывает, сколько слов было добавлено
- Сервис загружает список определений для каждого слова
- Сервис загружает перевод на базовый язык для каждого определения

Есть режим редактирования словаря:
- Пользователь видит список слов
- Пользователь видит количество определений для каждого слова
- Пользователь может удалить слово
- Пользователь может перейти в список определений для текущего слова
- Пользователь может удалить определение
- Пользователь может отредактировать определение
- Пользователь может отредактировать перевод определения
