- Сервис написан на TypeScript
- Для хранения данных использутеся PostgreSQL DB
- Бэкэнд принимает данные через RestAPI
- Бэкэнд отправляет данные в шину Mercure
- В данный момент никаких подключений к telegram или другим клиентским сервисам/приложениям нет. Реализуем только API + Mercure
- Авторизация реализована при помощи JWT
- Приложение должно иметь механизм миграций БД
- Приложение должно использовать docker и docker compose для развертывания
- Приложение должно иметь возможность запускаться локально без docker
- Приложение поддерживает возможность исполнять задачи асинхронно
