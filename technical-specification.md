# Техническое задание: Система изучения иностранных слов

## 1. Общее описание

Система предназначена для изучения иностранной лексики методом активного вспоминания (active recall). Пользователю предъявляется определение слова на изучаемом языке, и он должен воспроизвести само слово. Система поддерживает добавление пользовательских слов с автоматической обработкой: получение перевода, загрузка словарных определений и контекстов с их переводом на родной язык пользователя.

---

## 2. Архитектура

### 2.1 Общая архитектура

Система построена по принципу **микросервисной архитектуры**. Все сервисы написаны на **TypeScript**. Взаимодействие между сервисами осуществляется **асинхронно** через **брокер сообщений** (например, RabbitMQ или Kafka — подлежит уточнению).

## 3. Описание микросервисов

### 3.1 Core Service (Базовый сервис)

**Ответственность:**
- Хранение состояния пользователя (прогресс, настройки, изучаемый язык, родной язык)
- Маршрутизация входящих и исходящих сообщений через брокер
- Управление очередями задач для обогащения данных (перевод, определения)
- Оркестрация флоу тренировки

**Ключевые сущности:**
- `User` — профиль пользователя, его настройки и прогресс
- `Word` — слово на изучаемом языке
- `WordCard` — карточка: слово + перевод + список определений/контекстов (переведённых)
- `TrainingSession` — активная сессия тренировки

### 3.2 Translation Service (Сервис переводов)

**Ответственность:**
- Асинхронная загрузка перевода слова (изучаемый язык → родной язык пользователя)
- Перевод определений и контекстов на родной язык пользователя

**Интерфейс (входящие события):**
- `word.translate.requested` → `{ wordId, sourceLanguage, targetLanguage }`

**Исходящие события:**
- `word.translate.completed` → `{ wordId, translation }`

### 3.3 Definitions Service (Сервис определений)

**Ответственность:**
- Асинхронная загрузка словарных определений слова на изучаемом языке
- Загрузка контекстных примеров употребления

**Интерфейс (входящие события):**
- `word.definitions.requested` → `{ wordId, word, language }`

**Исходящие события:**
- `word.definitions.completed` → `{ wordId, definitions: string[], contexts: string[] }`

### 3.4 Auth Service (Сервис авторизации / аутентификации)

**Ответственность:**
- Регистрация и аутентификация пользователей
- Управление сессиями/токенами
- Унифицированная идентификация пользователей из разных frontend-каналов (Telegram, PWA)

## 4. Frontend-клиенты

Оба клиента подключаются к **Core Service** и отвечают исключительно за отображение данных и приём пользовательского ввода. Бизнес-логика тренировки находится на стороне Core Service.

### 4.1 Telegram Bot

- Взаимодействует с пользователем через Telegram API
- Отображает карточки (определение → ввод слова), принимает ответы, показывает результат

### 4.2 PWA (Progressive Web App)

- Веб-интерфейс, доступный с любого устройства
- Аналогичный функционал тренировки, расширенные возможности управления словарём
