# Project Agent Rules

## Strict Configuration & No Fallbacks (CRITICAL)

- **Никаких дефолтных значений и fallback'ов**:
  - **НИКОГДА** не использовать `.default(...)` в схемах Zod (особенно для переменных окружения) или fallback-значения (`|| '...'`, `?? '...'`).
  - Все конфигурации, порты, URL сервисов, провайдеры и модели должны быть строго и явно заданы в окружении (`.env`, docker-compose).
  - При отсутствии значения валидация должна строго падать (fail-fast), сигнализируя о неполной конфигурации.
  - Для тестов все необходимые параметры задаются явно в `.env` соответствующего сервиса, а не "зашиваются" дефолтами в коде.
